# 研究主题：Temporal Knowledge Reasoning

本文件是公开示例，与 `research_profile.temporal-kg.json` 成对。不会自动替代用户配置。研究主线统一为 **temporal knowledge reasoning（时态知识推理）**，以时态知识图谱推理为主要对象，重点关注 **Agent × TKG reasoning**。

## 主题边界

每篇推荐均须同时具有：

1. 知识对象：知识图谱、知识库或有结构的时态知识事实。
2. 时间建模：时间戳、事实有效期、时间区间、先后关系或时间约束。
3. 推理任务：时间约束多跳推理、时态问答、外推/插值、链接/事件预测、补全或规则推理。

Agent、LLM、记忆与 GraphRAG 是实现方法，不能单独成为推荐主题。普通 Agent memory、静态 KG、泛 GraphRAG、一般图学习、交通或其他时间序列研究，不因“可迁移到 TKG”或“可能有启发”进入精选，也不计入本主题活跃度。时间仅作为背景词的论文应在证据复核时排除。

程序用 topic_scope 的必要概念组进行准入，题名/摘要须满足所有组。它是可解释的关键词筛选，不证明论文实质贡献已核实。元数据不足时核对并补全原文摘要再筛，不靠评分加分越过主题边界。

## 阅读优先级与复核问题

- 同等级内首选 Agent 直接参与时态知识推理：时间约束下的规划、路径选择、工具调用、证据检索、验证或多智能体协作。
- 其次选择同主题的 LLM 方法、可信时态评测和重要传统 TKG 对照方法；不强制每篇都使用 Agent。
- 时态图谱记忆仅在明确支撑知识推理、时态问答或预测，并报告时间机制与推理评测时入选。
- 检查 Agent 相对单次 LLM、固定流程和传统方法的独立增益；核对消融、调用/token/时间成本和失败案例。
- 检查未来事实泄漏、检索索引泄漏、时间切分、强基线，以及代码、数据、提示词的可复现性。

每篇报告明确回答“推理什么知识、怎样建模时间、Agent 具体做什么（如适用）、相较已有方法改变什么”，用实际读过的摘要或全文链接支持，不补造实验结论。

## 查询、来源与补充

所有模式保持相同主题。agent_tkg 优先 Agent×TKG 查询，并检索同主题 LLM/TKG 对照；agent_memory 要求知识对象、时间和推理；benchmark_eval 只搜时态知识推理评测。兜底可以移除 Agent 限定，不能转向泛图学习或泛 Agent。

当前只启用 arXiv，OpenAlex、Crossref 暂停；Semantic Scholar 不自动启用。arXiv 不能覆盖全部会议/期刊，引用关注度缺值标未知，不能由来源减少推断领域升温。版本跟踪只调用启用来源；仅 DOI 的正式出版变化暂无法检查。

场所优先模式查看完整30天，A类优先；score 模式优先今天/昨天，候选不足再扩到7→14→30天。均标注实际日期，仍不足则少推或零推荐。主题/查询/来源变更使用独立观测范围；旧记录保留，不当作新范围的可比基线。

## 阅读重要性与数量

发表会议和期刊的含金量是本人的主要阅读依据；同主题内已核实 CCF A 类优先，再比较其他等级、Agent×TKG 相关性和研究贡献。会议与期刊分别保留名称和类型；不把未知期刊分区臆造为 CCF A 类。配置期刊分层如需补充，由可靠依据人工维护。

场所优先模式下，重要性分由场所60%与贡献40%组成，只表示个人阅读优先级。贡献部分仍核对原文，不把场所等级直接写成方法突破或 SOTA。每篇给出场所等级及正式论文页面证据；作者自述录用、简称歧义和附属卷不直接享受主会等级。

默认推荐目标从5篇提高到10篇，复核池从50篇提高到100篇。统一查看近30天同主题论文，按实际日期区分当日/近期补充。A类不足时可推荐同主题 B/C 类、其他期刊及有价值预印本，明确等级或待核实状态。仍不足时少推，不扩大主题。

当前默认收集 arXiv 元数据，所以需逐篇核对 DOI 落地页、官方会议论文集或期刊页面，确认是否正式发表及所属主会/长文。不得把“只查到 arXiv”写成“尚未录用”，也不自动恢复 OpenAlex/Crossref。
